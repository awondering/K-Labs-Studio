Organising a rod-building workbench

In brief

Set up a clear rod path with movable supports, useful sighting light and separate places for parts and measurements.

Give the rod an uninterrupted path

Set the hand wrapper where you can move its supports as you work along the blank. The CRB system provides an extra stand for the tip or butt. Dry-fit the longest job you expect to handle and check where each support can sit without crowding the working area.

Keep the thread path clear

Put the thread stand where it can feed through its tensioner without crossing the blank’s working area. Fuji’s hand-wrapper drawing identifies the thread stand and tensioner as part of that setup. Check that the rod and supports can move independently of the thread stand.

Give parts and notes fixed places

Lay guides in installation order in a tray beside the station, with tip top and trim pieces labelled separately. Keep the sketch or build sheet visible so you can compare the laid-out pieces and measurements without moving the blank off its supports.

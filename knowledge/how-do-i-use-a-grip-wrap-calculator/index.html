Using Studio’s Grip Wrap Calculator

In brief

Enter the straight or tapered grip dimensions, cover width and trimming allowance to estimate material for a continuous spiral wrap.

Enter the profile you are covering

In Studio, open Workshop → Grip Wrap. Choose Straight Grip for a constant diameter, or Tapered Grip for separate start and end diameters. Enter the covered length and the cover width or cord diameter, checking the displayed units before comparing the result with your stock.

Read the outputs separately

Theoretical Wrap Length is the modeled spiral. Material Required includes the trimming allowance you entered. A tapered profile also displays separate start and finish cut angles. Write down both the profile and the allowance so you can recreate the estimate later.

Keep the layout assumption visible

The calculator assumes turns meet without a gap or overlap. If your layout deliberately leaves a gap or overlaps the previous turn, treat this output as a different layout. If you use Print Cut Template, select actual size and check the printed calibration line.

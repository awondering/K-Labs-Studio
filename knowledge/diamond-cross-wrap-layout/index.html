Planning a diamond wrap in Thread Design Studio

In brief

Use the digital diamond layout to identify reference lines and crossing marks, and verify the printed scale before using a physical sample.

Set up a digital layout

Open the diamond design and enter the measured diameter at the area you plan to cover. Treat crossing spacing as a design input. In Studio’s base cylindrical model, the two reference lines are opposite one another. One set of marks falls half a spacing between the marks on the other line.

Read the marked plan

Use the marking guide and preview together to identify the start and which line each crossing belongs to. Check the printed scale before transferring the marks. The workshop view identifies the order of modelled passes and which direction the thread follows.

Keep the evidence with the design

The digital crossing positions and continuity of the thread paths are checked by the engine tests. The modelled thread sequence and any suggested starting spacing still need confirmation on a sample for your materials. Keep the printed plan and record changes made on the sample separately.

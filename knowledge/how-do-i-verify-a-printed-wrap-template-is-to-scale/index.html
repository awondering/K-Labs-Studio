How to check a printed wrap template is to scale

In brief

For a full-circumference template, compare its printed width with the stated circumference. For a diamond marking guide, measure along a mark column.

Why the width matters

A full-circumference wrapping template is drawn one circumference wide. Print scaling changes the dimensions of that pattern. A diamond marking guide is a different layout, with two columns of axial marks. Its page width does not represent the rod circumference.

The check

  1. Print with page scaling turned off (actual size, or 100%).
  2. On a full-circumference template, measure the outlined pattern width with a ruler.
  3. Compare that width with the printed circumference, allowing for rounding on the label.

Working out the scale

Scale = measured width ÷ stated circumference × 100. A template stating 37.7 mm that measures 35.8 mm is approximately 95% of actual size. Reprint with scaling turned off rather than correcting by hand.

In Studio

The grid wrapping template in Thread Design Studio prints the rod diameter, circumference and mark spacing. Its outlined pattern is one circumference wide. On the diamond marking guide, compare the distance between two consecutive marks in the same column with the printed crossing spacing. Use actual size for both.

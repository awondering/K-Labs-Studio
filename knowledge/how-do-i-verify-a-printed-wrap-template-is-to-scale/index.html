How to check a printed wrap template is to scale

In brief

Measure the printed template's width and compare it with the circumference printed on it. If they differ, the print was scaled; work out by how much.

Why the width matters

A wrapping template is drawn at full size, so its width equals the rod's circumference and it goes once around the rod. If the print is scaled, the width and every mark spacing change in the same proportion, and the pattern no longer meets itself.

The check

  1. Print with page scaling turned off (actual size, or 100%).
  2. Measure the template's outlined width with a ruler.
  3. Compare it with the circumference printed with the template.

Working out the scale

Scale = measured width ÷ stated circumference × 100. A template stating 37.7 mm that measures 35.8 mm was printed at 95%. Reprint with scaling turned off rather than correcting by hand.

In Studio

Thread Design Studio's wrapping template prints the rod diameter, the circumference, the number of marks and their spacing, with the instruction to print at 100% (no scaling). The outlined pattern is drawn one circumference wide.

Arithmetic: a full-size wrap template is one circumference wide. The worked figures are recalculated by K-Labs automated tests; the Thread Design Studio statements are checked against Studio itself.

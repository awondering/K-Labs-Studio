Recording a customer deposit on a rod build

In brief

Keep the agreed deposit requirement separate from the payment received, then check the balance against the saved payment record.

Distinguish the requirement from the receipt

The quote can state the deposit expected before work starts. When money arrives, record the actual payment against the matching build. For example, if the customer sends only part of the deposit, keep both the agreed requirement and the received amount visible.

Verify the saved payment

Studio records a deposit or balance payment on a saved, synchronised build and waits for server confirmation. If that confirmation is interrupted, use Confirm Pending Transaction on that build before another attempt. Check the resulting payment status and balance.

Match the customer’s paperwork

Use the build reference when checking the payment against the customer’s transfer. Review the customer-facing document for the amount received and any balance owing. Keep the payment reference in the workshop’s payment record for follow-up.

Numbering guides on a spiral-wrapped rod

In brief

Pick a numbering direction and record guide position and rotation separately so transition guides can be identified without guessing.

Name the direction before assigning numbers

A spiral train has guides at different rotations between the reel and the underside. For a workshop drawing you can number from the reel toward the tip. Write that direction at the top of the drawing and state whether the tip top is counted or listed separately.

Give each transition guide its own row

Record the number, the position along the blank, the distance reference and the viewing direction used for rotation. For example, identify the first transition guide by its station and angle rather than merely writing “side guide.”

Translate supplier diagrams explicitly

If an existing diagram numbers from the other end, write both identifiers beside the corresponding part before you copy dimensions. Keep the same identifiers on the temporary layout and finished record so a later repair refers to the right guide.

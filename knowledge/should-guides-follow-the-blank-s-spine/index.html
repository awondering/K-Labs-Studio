Do rod guides need to follow the blank spine?

In brief

Treat the blank’s preferred flex orientation and visible straightness as separate observations when selecting a guide reference.

Separate the two observations

RodMaker author Tom Kirkman uses spine for a preferred flex orientation of a rolled blank. The axis you see as straightest when sighting down the blank can be different. A mark for one observation does not tell you where the other lies.

Choose a guide reference you can reproduce

Follow any model-specific instruction first. When comparing possible orientations, note which makes the tip and handle line up visually in the intended fishing position. Record the reference you chose so the seat and guide layout can be checked from the same view.

Keep rotational behaviour in context

A preferred orientation observed on the bare blank is different from the moment that line force can produce through a guide at an offset from the rod axis. Kirkman discusses these as separate effects. Use the guide layout and reel orientation when reviewing line-induced roll.

Tom Kirkman, RodMaker Magazine, Rod Spine (https://www.rodmakermagazine.com/wp-content/uploads/2024/05/rodspine.pdf) | OpenStax, University Physics Volume 1, 10.6 Torque (https://openstax.org/books/university-physics-volume-1/pages/10-6-torque)

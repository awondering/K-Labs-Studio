What a rod build confirmation should include

In brief

Confirm the agreed rod, major parts, expected completion and payment position before the job proceeds through the workshop.

Show the rod the customer approved

Identify the customer and build, describe the agreed rod, and list the major specifications and components that define the order. If the reel seat or finish colour was a decisive choice, make it easy for the customer to find that detail.

Make timing and amounts easy to read

State the estimated completion date if known, how the rod is to be handed over, the agreed total and any actual payments. Check whether a deposit is still due before you send. In Studio, preview Build Confirmation from the active build.

Review substitutions against the order

Check the confirmation against the accepted quote before sending, especially if a part was changed or a delivery option was added. Keep the agreed change with the build so the confirmation and bench record can be traced back to the same decision.

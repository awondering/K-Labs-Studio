Choosing the number of running guides on a rod

In brief

Start with a layout for the actual blank and guide system, then review the running section where the line path and blank curve differ.

Define which guides you are counting

On the bench sheet, separate the reduction or entry guides, the transition, the runners and the top. A count copied from a chart is useful only when you know which of those pieces it includes. Fuji’s reference drawings describe the guide roles as well as their stations.

Look at the shape of the running section

Compare the guide stations with the assembled blank and the recorded line path from the layout check. Mark long spans where the line takes a different path from the bend. Before adding a runner, consider which neighbouring guide positions were actually checked and what the proposed change is meant to address.

Record the reason for the final count

If a runner was added near the tip, identify the span it divided and keep both versions of the layout in the job notes. The same nominal rod length can take a different arrangement when the blank or the guide heights change.

Planning guide spacing on a level-wind casting rod

In brief

Use the fitted casting reel and its level-wind entry path to choose a starting layout, then record each guide’s station and role.

Fit the reel before copying a chart

Mark the reel-seat position and identify the line exit from the intended reel. Fuji’s baitcasting documentation uses the level wind as an entry reference. Use the casting section for this setup, since a fixed-spool spinning layout starts from a different line path.

Draw the height changes as well as the gaps

Place each candidate guide on the bench plan with its ring height and distance from your chosen reference. Inspect the path through the first group from the fitted reel. If a frame substitution changes the height, review the adjacent positions before treating an old spacing figure as settled.

Document the starting layout clearly

Record whether the plan is guides-on-top or spiral and list the tip top separately from numbered guides if that is your convention. Mark which figures came from the reference and which describe your own temporary layout, so later verification can be traced to the actual build.

Fuji Kogyo, 2023 reference guide specifications (https://www.fujitackle.com/cms-fuji/wp-content/uploads/2023/04/01_intro.pdf)

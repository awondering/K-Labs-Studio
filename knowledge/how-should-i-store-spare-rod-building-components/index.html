Organising spare rod-building components

In brief

Store loose parts under their model and dimensions so an exact replacement can be identified when a job returns to the bench.

Keep the useful label with the part

Use labelled compartments for each exact guide model and size. For a tip top, keep both its ring designation and tube size. A loose top that looks right from above can have a different tube, so avoid relying on appearance when returning it to stock.

Store the comparison details

Keep thread family, colour code and size with the spool, even when several products share a colour name. For handle components, keep the supplier code and fit dimension with the part. Use the same fields on the build sheet so inventory and the installed part can be matched.

Separate leftovers from job stock

When a job is done, check the component list before returning unused parts. Put an unidentified spare in its own compartment until measured and identified. That preserves the meaning of the bin labels for the next order.

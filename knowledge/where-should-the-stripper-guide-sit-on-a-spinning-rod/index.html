Placing the stripper on a spinning rod

In brief

Start stripper placement with the fitted reel and review the first guide as part of the whole reduction train.

Set the reel reference

Fit the intended reel before taking the first distance. Note the spool position and which face or point you measured from. A spacing figure copied from someone else’s bench needs its original reference and guide model to be useful.

Compare position and height together

Try the first guide alongside the rest of the reduction group. Look through the side profile from the spool to the transition. If the line approach looks abrupt, compare the guide’s height with the reference layout before moving it. The same nominal ring label can appear on different frame heights.

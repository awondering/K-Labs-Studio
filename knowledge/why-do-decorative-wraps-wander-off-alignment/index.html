Why decorative rod wraps drift off alignment

In brief

Check the axial reference marks, starting station and pass direction before treating a crossing that wanders as a thread-spacing problem.

Find the first crossing that moved

Compare the first misplaced crossing with its reference mark. If crossings are already offset at the first pass, look at the start station and line identity. A change that begins later is easier to isolate when you can name the first mark and pass where it appears.

Check the reference lines as a pair

Studio’s base diamond uses opposite A and C reference lines with staggered axial marks. Make sure you are reading the correct column before comparing a crossing with the marking guide. Other patterns can use different mark arrangements.

Keep the digital and physical checks distinct

Print template marks as intended by the tool and verify scale before transferring them. The digital geometry and crossing positions are tested in Studio. A physical sample lets you see whether the marks and the actual thread pass agree on your blank.

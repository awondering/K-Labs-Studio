What fishing rod guide size numbers mean

In brief

Read the catalogue dimension key before treating a guide size number as the opening available to line and knots.

Read the drawing

Treat the catalogue size as a designation for that ring family. Check the clear opening and, where relevant, frame height separately. Fuji’s TORZITE documentation distinguishes the ring size from the inside opening when comparing ring designs.

Write down all the dimensions you need

When specifying a replacement, record the frame model, ring designation and relevant dimensions. A tip-top listing can include a separate pipe size. For Fuji LG, use the ring-and-pipe listing and the dimension drawing together rather than using the tube’s outside diameter as the blank fit.

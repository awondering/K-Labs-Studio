Reading a rod’s casting-weight rating

In brief

Use the stated lure weight range for the exact model and keep its units and meaning separate from line rating, power and action.

Read the heading and units

St. Croix’s Premier tables have separate columns for lure weight in ounces and line weight in pounds. Read from the exact model row and record the heading with the amount. A model name or a power label alone does not convey that figure.

Compare using one unit

Weigh the rig you intend to cast and use the same units as the model table. For example, if the rig changes from a bare lure to a lure with added casting weight, record both actual rig weights so the change stays visible when you compare models.

Keep the rating tied to its application

Record the maker and exact model beside the figure. If a listing gives a jigging or trolling specification, consult the maker for how to interpret it for the intended use. Leave unspecified casting figures blank on the build sheet.

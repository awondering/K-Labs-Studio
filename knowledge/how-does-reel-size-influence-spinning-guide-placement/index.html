How reel size affects spinning guide placement

In brief

Measure the reel in its seat and use the spool position and height when comparing reduction layouts for a spinning rod.

Measure the fitted reel

Fit the reel you will build around and note the spool diameter, its position relative to the seat and its height above the blank. Use the same reference when comparing another reel. A size label on the box does not tell you where that reel puts the spool on your particular handle assembly.

Compare the reduction guides together

Position the first guide as part of the reduction group and look through to the transition into the runners. If a taller reel changes the line approach, compare frame height as well as ring size. Treat a spacing calculator as a starting layout for the reel and guide system it describes.

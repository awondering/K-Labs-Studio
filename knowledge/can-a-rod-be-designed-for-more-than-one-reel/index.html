Designing a rod for more than one reel

In brief

Set up the rod around its primary reel and compare the alternatives by reel position, line path and clearance before fixing the guides.

Choose the primary outfit

Write down the reel, main line and leader the customer expects to fish most. Take reduction-guide measurements with that reel fitted. If a second spinning reel sits higher or has a different spool position, keep its measurements in a separate row so you can see what changed.

Compare the swap

Mock up the guide train before wrapping it. Fit each reel in turn and look along the path into the first guides. A reel that fits the seat can still put the line in a different place relative to the stripper. For example, if the alternate setup uses a heavier leader, check both that entry path and the knot through the smallest guides and top.

Choosing a tip-top guide for a rod blank

In brief

Specify the tube fit and the line opening separately when replacing a tip top or ordering one for a new blank.

Measure the fitting location

Compare the blank at the fitting location with the specified inside diameter of the tube. On Fuji’s LG sheet, ring and pipe sizes are listed together, while the drawing’s O/D column describes the tube exterior. Use the pipe fit and the units specified for the exact model.

Check the line opening

Compare the clear opening with the last running guides and the actual leader knot. For example, if a top has the right tube but catches the knot that passes through every runner, keep the tube requirement and look for a different ring option. Record the exact model and both sizes on the build sheet.

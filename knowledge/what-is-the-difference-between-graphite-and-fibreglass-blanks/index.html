Comparing graphite and fibreglass rod blanks

In brief

Identify the material and construction, then compare exact blank models by application, weight and action before choosing between them.

Read how the maker describes the blank

Graphite is the usual catalogue term for carbon-fibre rod construction. Fibreglass models use glass reinforcement. Catalogue families can also include hybrids. Read the builder’s material notes as well as the table of model specifications.

Compare actual candidates

A fibre label alone does not specify the finished blank’s action, power or weight. St. Croix’s Legend Glass range, for example, uses Linear S-Glass across models with several power ratings. To compare two crankbait blanks, hold the intended lure and technique constant and line up the model rows beside each other.

Write down what matters to the build

Record the listed application, the action and power, and the blank weight if available. If a model appeals because of the way an existing rod fishes, keep that rod as a separate handling reference alongside the catalogue comparison.
